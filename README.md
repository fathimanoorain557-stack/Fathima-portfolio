# Fathima Noorain - Student Portfolio

A responsive student portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html` and select **Open with Live Server**.

## Files
- `index.html` — page structure
- `css/style.css` — styling and responsive layout
- `js/script.js` — mobile navigation and active navigation behavior

Note: The resume file is not included yet. Add your real resume as `assets/resume.pdf` when ready.
